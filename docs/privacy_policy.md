# Academia Shield Student Transparency Notice & Privacy Policy

## 1. Core Commitment: Zero Stealth & Visible Consent
Academia Shield is built strictly as an educational endpoint governance tool, **NOT spyware or surveillance software**. We uphold strict student privacy guarantees:

1. **No Invisible Execution**: The Academia Shield student agent is installed with explicit student/institution knowledge and clearly indicates when an authorized session is active.
2. **Session-Bound Only**: Policies and temporary restrictions are enforced **only during active classroom sessions or exams**. When the class session ends, all restrictions immediately cease.
3. **Fail-Safe Self-Restoration**: If the classroom server disconnects for more than 120 seconds, the agent automatically unlocks all restrictions to prevent student inconvenience.

---

## 2. What Academia Shield NEVER Collects (Strict Prohibitions)
To protect student privacy, Academia Shield agent software is engineered with hardcoded architectural safeguards that prohibit the collection of:
- ❌ **No Keystroke Logging**: Keystrokes, passwords, and clipboard data are never logged or accessed.
- ❌ **No Screen Recording / Webcam / Microphone Access**: Video, audio, and screen pixels are never captured.
- ❌ **No Personal File Scanning**: Personal documents, photos, browser history, or private directories are never scanned or uploaded.
- ❌ **No Geolocation Tracking**: Physical GPS coordinates or Wi-Fi triangulation data are never collected.

---

## 3. What Academia Shield Collects & Why

| Data Category | Specific Data Points | Purpose | Retention |
| :--- | :--- | :--- | :--- |
| **Institutional Identity** | Student Name, School Email, Roll Number | Authentic class enrollment and roster management | Academic Term |
| **Device Metadata** | Device Identifier, OS Version, Agent Version | Ensure endpoint policy delivery compatibility | Active Enrollment |
| **Session Events** | Session Join/Leave Time, Policy Applied | Verifiable attendance & participation verification | 30 Days (Audit Log) |
| **Safety Violations** | Attempted visit to blocked URL or launching blocked game during exam | Live instructor notification for exam integrity | Session Audit Log |

---

## 4. Student Rights & Control
- **View Active Policy**: Students can open the Academia Shield interface at any time to inspect every blocked website, application, and USB policy.
- **Request Assistance / Unlock**: Students can submit an in-session unlock request to their professor if they need legitimate access to a blocked resource for coursework.
- **Revoke Device**: Students or IT administrators can unenroll a personal device from the institutional portal at any time.
